Press Build & Run to compile and test your code.
Left stick = Axis4/Axis3 · Right stick = Axis1/Axis2
Functions you can use
  • Move(int left, int right) drive motors, −100 to 100 (negative = forward)
  • BStop() / CStop() stop the drive
  • RunRoller(int val) / StopRoller()
  • RunArm(int val) / StopArm() arm motor, −100 to 100
  • wait(int ms, msec) pause this task
  • Controller1.Axis1…Axis4.position(percent) −100 to 100
  • Controller1.ButtonA/B/X/Y/L1/L2/R1/R2/Up/Down/Left/Right.pressing()
  • Tilt.set(bool) Clamp.set(bool) Claw.set(bool) (Claw true = closed)
  • Field: carry the orange block and the purple high block (needs the arm raised to 70 or more) into the goal circle, and flip the wall switch by extending the Tilt at the top wall.
  • task t = task(MyFunction); start a task
